# Phase 0: 書く力をつける

PHP の基本構文・クラス・モダンPHP(Composer/PSR-4)を、**写経 → 再現 → 自力** の3段階で身につけるフェーズ。

## このフェーズの目的

「PHP のコードは読めるけど、ゼロから自分で書けない」状態を解消する。
小さなコードを毎日書く習慣を作り、要件を渡されたら自分でコードに落とせるようにする。

## ゴール

1. PHP の基本構文(変数・配列・ループ・条件分岐・関数)を何も見ずに書ける
2. 簡単なクラスを何も見ずに書ける(プロパティ・コンストラクタ・メソッド)
3. 与えられた要件(20〜30行程度)を、ヒントなしでコードに落とせる
4. インターフェースと抽象クラスの違いを、コードで示しながら説明できる
5. PHP独自の重要要素(`==`/`===`、nullable、`strict_types`、リクエストモデル、スーパーグローバル、Enum)を理解し、Laravel 学習の準備ができている
6. Composer と PSR-4 を使ったモダンPHPプロジェクトをゼロから構築できる

## 進め方

### 1. 問題を見る

`blockX/problems/sXX_xxx.md` を開いて、問題文を読む。

### 2. 自分で書く

`blockX/my_answers/sXX_xxx.php` を作成して、自力で書く。
**まずは答えを見ずに挑戦すること**。

### 3. 動かす

```bash
php blockX/my_answers/sXX_xxx.php
```

期待通りの出力になるか確認する。

### 4. 詰まったら解答を見る

`blockX/solutions/sXX_xxx.php` と `blockX/solutions/docs/sXX_xxx.md` を開いて、解答と解説を読む。

### 5. 解答を見たら、再度自力で書く

解答を見た後は、ファイルを閉じて何も見ずにもう一度書く。
これをやらないと「読めるけど書けない」が解消されない。

## Step の種類

| 種類 | 進め方 |
|------|-------|
| 写経Step | 解答を見ながら書く → 閉じて再現 → 動かす |
| 自力Step | 問題文だけ見て自力で書く → 詰まったら解答を見る → 再度自力で書く |
| ドキュメント読みStep | 指定された公式ドキュメントを時間内に読む(理解より把握優先) |
| 概念Step | AI に質問してノートアプリに自分の言葉で整理する |

## 学習の運用ルール

1. **継続最優先**: 1日1Stepでも続けることが最重要。完璧主義は禁物
2. **小さく書く**: 毎日少しでも手を動かす
3. **詰まってOK**: 詰まったら解答を見て、その後再度自力で書く
4. **Block完了テスト**: 各Blockの最後にテストがある。詰まったらそのBlockを繰り返す
5. **リファレンスを育てる**: 学習中に出会った汎用知識は `~/playground/references/` に蓄積する

## 期間の目安

1〜2ヶ月。Phase 0 は最重要なので、時間をかけて良い。

## 完了条件

各Block完了テスト(`B1-T1`、`B2-T1` など)と Phase 0 修了テスト(`PHP-FINAL-T1`)に合格すること。
