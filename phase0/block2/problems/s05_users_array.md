# S05: ユーザーの配列を作って一括処理

`User` クラスのインスタンスを5人分作って配列に入れ、`foreach` で全員の自己紹介を出力してください。

## 制約

- `User` クラス(S01〜S03 で作ったもの)を使う
  - プロパティ: `$name` (string)、`$age` (int)
  - コンストラクタで初期化
  - `introduce()` メソッドが「私は◯◯です。◯◯歳です。」と返す or 出力する
- ユーザーを **5人分** 作って、配列に入れる
- `foreach` で配列を回し、全員の `introduce()` を呼ぶ
- `declare(strict_types=1);` を先頭に書くこと

## 出力例

```
私は田中です。25歳です。
私は鈴木です。30歳です。
私は佐藤です。28歳です。
私は山田です。35歳です。
私は伊藤です。22歳です。
```

(名前と年齢は自由に決めてOK)

## ファイル名

`my_answers/s05_users_array.php`

## ヒント

<details>
<summary>クリックして表示</summary>

- 配列の作り方は2通りあります:
  - 1人ずつ `$users[] = new User(...)` で追加
  - `$users = [new User(...), new User(...), ...]` で一気に作る
- `foreach ($users as $user)` で1人ずつ取り出せる
- `User` クラスを同じファイル内に再定義してOK(クラスファイルの分割は B4 で扱います)

</details>
