# S07: Dog クラス(継承とオーバーライド)

S06 で作った `Animal` クラスを継承して、`Dog` クラスを定義してください。

## 制約

- クラス名: `Dog`
- `Animal` クラスを継承する(`extends Animal`)
- `speak()` メソッドをオーバーライドして、「(名前): ワンワン!」と返すように変更する
- `Animal` クラスは S06 と同じものを再利用してOK(同じファイル内に再定義する)
- `declare(strict_types=1);` を先頭に書くこと

## 動作確認(`main` 部分)

クラス定義の下に、以下を行うコードを書いてください。

1. `Dog` を1つ作る(例: 名前 `"ポチ"`)
2. `speak()` の戻り値を `echo` で表示

## 出力例

```
ポチ: ワンワン!
```

## ファイル名

`my_answers/s07_dog.php`

## ヒント

<details>
<summary>クリックして表示</summary>

- 継承の書き方は Java と同じ感覚: `class Dog extends Animal`
- 子クラスでコンストラクタを書かなければ、親のコンストラクタがそのまま使われる(今回はこれでOK)
- オーバーライドは、親と同じ名前・同じシグネチャのメソッドを子クラスで再定義するだけ
- 子クラスから親の `protected $name` にアクセスできる(`$this->name` で参照可)

</details>
