## 学習のコツ

### Java Silver 保持者として有利な点

PHP のインターフェースは **Java の interface とほぼ同じ概念**。
「Java の interface は分かる」と思っているなら、その理解の 9 割はそのまま使える。

ただし微妙に違う部分がある:

- PHP のインターフェースでも**定数**は宣言できる(Java も同じ)
- PHP のインターフェースには**デフォルト実装が書けない**(Java は `default` メソッドで書ける)
- PHP では一つのクラスが**複数のインターフェースを実装できる**(Java と同じ)

「Java の interface とほぼ同じ。ただし `default` メソッドは無い」くらいの理解で十分。

### ありがちな曖昧ポイント(無理に今解消しなくてよい)

このStepで完璧を目指さなくてよい。以下は S12〜S14 で実装しながら自然に分かってくる:

- 「なんでわざわざインターフェース挟むの? クラス直接使えばいいじゃん」
- 「`implements` と `extends` の違いって、結局なに?」
- 「型として使う」ってどういうこと?

「今は曖昧」とメモに書いておくだけでOK。
