# S09: ポリモーフィズムを体験する

`Animal`、`Dog`、`Cat` を使って、配列に動物を混ぜて入れ、全員の鳴き声を出力してください。

## 制約

- `Animal`、`Dog`、`Cat` クラスは S06〜S08 のものを使う(同じファイル内に再定義してOK)
- `Dog` と `Cat` をそれぞれ複数作って、**1つの配列にまとめる**
- `foreach` で配列を回し、全員の `speak()` を呼んで出力する
- `declare(strict_types=1);` を先頭に書くこと

## 動作確認

以下を含むコードを書いてください:

1. `Dog` を2匹、`Cat` を2匹作る(名前は自由)
2. それらを **同じ配列** に入れる(犬と猫が混ざった配列になる)
3. `foreach` で全員の `speak()` を呼ぶ

## 出力例

```
ポチ: ワンワン!
タマ: ニャー
シロ: ワンワン!
ミケ: ニャー
```

(順序や名前は自由。Dog と Cat が混在していて、それぞれの `speak()` が呼ばれていればOK)
