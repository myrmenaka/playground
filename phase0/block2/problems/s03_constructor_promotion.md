# S03: コンストラクタプロモーションでUserクラスを書き直す

S01 で書いた `User` クラスを、PHP 8.0 で導入された**コンストラクタプロモーション**を使って書き直してください。

## 進め方

このStepは**写経Step**です。

1. `solutions/s03_constructor_promotion.php` を見ながら写経する
2. 動作確認後、ファイルを閉じて何も見ずに再現する
3. 余裕があれば、プロパティを1つ追加(例: `email`)してプロモーション形式で書いてみる

## 仕様

- ファイル先頭で `declare(strict_types=1);` を宣言する
- `User` クラスを定義する
- コンストラクタの引数に**可視性修飾子**(`private`)と**型宣言**を直接書くことで、プロパティ宣言と代入を省略する
- `introduce()` メソッドは S01 と同じ
- インスタンスを1つ作り、`introduce()` を呼んで結果を出力する

## 出力例

```
私の名前はAlice、年齢は25歳です。
```

## ファイル名

`my_answers/s03_constructor_promotion.php`
