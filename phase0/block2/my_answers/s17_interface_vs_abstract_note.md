## 3. 文法上の違い

| 観点 | インターフェース | 抽象クラス |
|------|----------------|----------|
| キーワード | interface | abstract |
| プロパティを持てるか | 持てない | 持てる |
| コンストラクタを持てるか | 持てない | 持てる |
| メソッドの実装を持てるか | 持てない | 持てる |
| 多重実装/継承 | できる | できない |
| インスタンス化 | できない | できない |


## 4. どう使い分けるか(自分の言葉で)

- インターフェースを使うのはこういう時: ルールだけ決めて、実装は自由にしたいとき
- 抽象クラスを使うのはこういう時: 処理も含ませたいとき
