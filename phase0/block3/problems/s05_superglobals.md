# S5: スーパーグローバル変数を使ったフォーム処理

## 目的

Laravel に隠蔽される前の「素の PHP」で、フォーム処理を最後まで書く。
`$_GET` / `$_POST` / `$_SESSION` を直接触ることで、Laravel の `$request` や `session()` が
裏で何をやっているかが見えるようになる。

## なぜこれをやるか

- Laravel の `$request->input('name')` は、内部的には `$_POST['name']` を呼んでいる
- Laravel の `session()->put('user', $user)` は、内部的には `$_SESSION['user'] = $user` をやっている
- この「素の姿」を見ておくことで、Laravel が何を隠蔽してくれているかが分かる
- 「フレームワークが面倒を見てくれている部分」を自覚できると、トラブル時の切り分けがしやすくなる

## 取り組み方

### 写経パート

1. `solutions/s05_superglobals.php` を `my_answers/s05_superglobals.php` に書き写す
2. ファイルがあるディレクトリで PHP のビルトインサーバーを起動:
```bash
   cd ~/playground/phase0/block3/my_answers
   php -S localhost:8000
```
3. ブラウザで `http://localhost:8000/s05_superglobals.php` を開く
4. フォームに入力 → 送信 → 結果が表示されることを確認
5. ページをリロードして、セッションに保存された訪問回数が増えることを確認

### 自力Stepパート

写経が終わって動作確認できたら、以下を **自力で** 追加する:

1. フォームに「年齢」入力欄を追加
2. 送信時に年齢もセッションに保存
3. 年齢が空欄、または数字以外、または0未満なら「年齢が不正です」と表示
4. 「セッションをクリア」というリンクを追加して、`?clear=1` で訪問回数と保存データをリセットできるようにする

ファイル名は `my_answers/s05_superglobals.php` のまま改造してOK。

## 動作仕様(写経パート)

### GET でアクセスしたとき

1. 訪問回数(`$_SESSION['visit_count']`)を1増やす
2. 最後に入力した名前(`$_SESSION['last_name']`)があれば表示
3. 名前を入力するフォームを表示

### POST でアクセスしたとき

1. `$_POST['name']` を取得
2. バリデーション: 空欄なら「名前は必須です」と表示
3. OKなら `$_SESSION['last_name']` に保存して挨拶を表示
4. その下にフォームを再表示

## 出力イメージ

初回アクセス:
```
訪問回数: 1 回目
名前を入力してください:
[ 入力欄 ] [送信]
```

名前を入力して送信後:
```
訪問回数: 2 回目
こんにちは、Alice さん!
前回の名前: Alice
名前を入力してください:
[ 入力欄 ] [送信]
```
