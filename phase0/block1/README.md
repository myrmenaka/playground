# Block 1: PHP の基本構文を体に染み込ませる

変数・配列・制御構文・関数を、写経と自力Stepで身につける。
「読めるけど書けない」状態を解消するための、Phase 0 の最初の関門。

## このBlockのゴール

- 変数宣言、配列操作、制御構文、関数定義を何も見ずに書ける
- PHP らしい書き方(`{$var}` 展開、`array_filter` など)が使える
- 型宣言と `declare(strict_types=1);` を当たり前に書ける
- Block完了テスト(B1-T1、B1-T2)に合格する

## Step 一覧

### 変数と出力

| Step | 種類 | 内容 |
|------|------|------|
| S1 | 写経 | `Hello, World!` を `echo` で出力 |
| S2 | 写経 | string、int、bool の3変数を `var_dump` で出力 |
| S3 | 自力 | 自己紹介プログラム(名前・年齢を埋め込む) |
| S4 | 写経 | ヒアドキュメント(`<<<EOT`)で書き直す |
| S5 | 写経 | 文字列に変数を埋め込む3パターン(連結・展開・sprintf) |

### 配列

| Step | 種類 | 内容 |
|------|------|------|
| S6 | 自力 | インデックス配列を全て出力 |
| S7 | 自力 | 連想配列(name/age/email)を全て出力 |
| S8 | 写経 | 連想配列の配列(ユーザー3人)から name を表示 |
| S9 | 自力 | 配列に値を追加する3パターン |
| S10 | 自力 | 配列から値を削除する2パターン |

### 制御構文

| Step | 種類 | 内容 |
|------|------|------|
| S11 | 自力 | 1〜10 を `for` で出力 |
| S12 | 自力 | 配列を `foreach` で全部出力 |
| S13 | 写経 | `foreach` でキーと値をセットで出力 |
| S14 | 自力 | 偶数 / 奇数判定の `if` 文 |
| S15 | 写経 | 上を `match` 式で書き直す(PHP 8 の新機能) |

### 関数

| Step | 種類 | 内容 |
|------|------|------|
| S16 | 自力 | `add($a, $b)` で2つの数を足す |
| S17 | 写経 | 上に型宣言を追加(`int $a, int $b): int`) |
| S18 | 自力 | `sum(array $nums): int` で配列の合計 |
| S19 | 自力 | 偶数だけの配列を返す関数 |
| S20 | 写経 | 上を `array_filter` で書き直す |

## Block 1 完了テスト

| Test | 内容 |
|------|------|
| B1-T1 | 整数配列を受け取り、偶数の合計を返す関数 |
| B1-T2 | ユーザー配列から、20歳以上の name だけを返す関数 |

両方できたら Block 2 へ。詰まったら Block 1 を再度繰り返す。

## ディレクトリ構成

```

│   └── ...
├── solutions/             ← 解答コード
│   ├── s01_hello.php
│   ├── s02_vars.php
│   └── docs/              ← 解説Markdown
│       ├── s01_hello.md
│       ├── s02_vars.md

    ├── s02_vars.php
    └── ...
```

## 進め方の例(Step ごと)

### 写経Stepの場合

1. `problems/sXX_xxx.md` を読む
2. `solutions/sXX_xxx.php` を見ながら `my_answers/sXX_xxx.php` に写経
3. 動かす
4. ファイルを閉じて再現

### 自力Stepの場合

1. `problems/sXX_xxx.md` を読む
2. `my_answers/sXX_xxx.php` を作って自力で書く
3. 動かして期待通りか確認
4. 詰まったら `solutions/` を見る → 再度自力で書き直す
