# S11 解説: 1から10までの数値出力

## ポイント

### `for` 文の3要素

```php
for (初期化式; 継続条件式; 更新式) {
    // 繰り返し実行する処理
}
```

- **初期化式** (`$i = 1`): ループ開始時に1回だけ実行される
- **継続条件式** (`$i <= 10`): 各反復の前に評価され、`true` の間ループが続く
- **更新式** (`$i++`): 各反復の最後に実行される

Java とまったく同じ構文。

### 改行コードの選択肢

| 書き方 | 説明 |
|--------|------|
| `"\n"` | LF(Unix系) |
| `"\r\n"` | CRLF(Windows) |
| `PHP_EOL` | 実行環境のOSに応じた改行コードを自動選択 |

CLI で実行するスクリプトでは `PHP_EOL` が無難。HTMLを出力する場合は `<br>` を使う(改行コードはブラウザで意味を持たない)。

## 別解

### ダブルクォートによる変数展開

```php
for ($i = 1; $i <= 10; $i++) {
    echo "$i\n";
}
```

`.` 連結より短く書ける。シングルクォートでは変数展開も `\n` も効かないので注意。

### `range()` + `foreach`

```php
foreach (range(1, 10) as $i) {
    echo $i . PHP_EOL;
}
```

PHP らしい書き方。`range(1, 10)` は `[1, 2, 3, ..., 10]` の配列を生成する。今回の課題では `for` 縛りなので使えないが、覚えておくと便利。

### `printf`

```php
for ($i = 1; $i <= 10; $i++) {
    printf("%d\n", $i);
}
```

書式指定が必要な場面で使う。

## つまずきやすい点

### 1. シングルクォートで `\n` を書く

```php
echo $i . '\n';   // ❌ 「1\n2\n...」と文字列として出力される
echo $i . "\n";   // ⭕ 改行される
```

シングルクォート内ではエスケープシーケンスが解釈されない(`\\` と `\'` だけは例外)。

### 2. 条件式の `<` と `<=` の混同

```php
for ($i = 1; $i < 10; $i++)   // 1〜9 までしか出力されない
for ($i = 1; $i <= 10; $i++)  // 1〜10 が出力される
```

「以下」か「未満」かは要件次第。配列のインデックスで回す時は `$i < count($array)` のように `<` を使うことが多い。

### 3. インクリメントの位置

```php
$i++   // 後置: 値を返してから増やす
++$i   // 前置: 増やしてから値を返す
```

`for` の更新式ではどちらも結果は同じだが、式の中で値を使う場合は挙動が異なる。

## Java との対比

```java
// Java
for (int i = 1; i <= 10; i++) {
    System.out.println(i);
}
```

```php
// PHP
for ($i = 1; $i <= 10; $i++) {
    echo $i . PHP_EOL;
}
```

| 観点 | Java | PHP |
|------|------|-----|
| 構文 | 同じ | 同じ |
| 変数の型宣言 | `int i` 必須 | 不要(`$i` で動的に扱う) |
| 変数のプレフィックス | なし | `$` 必須 |
| 出力 | `System.out.println()` | `echo` + 改行コード |
| 改行を含む出力 | `println()` が自動で改行 | `echo` は改行しないので明示が必要 |

`for` の制御構文自体は Java と PHP でほぼ同一。`$` と改行の扱いだけ意識すれば、Java の知識をそのまま使える。
