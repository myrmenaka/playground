# PHP-B1-S6: 解説

## 解答コード

```php
<?php

$nums = [10, 20, 30, 40, 50];

echo $nums[0] . PHP_EOL;
echo $nums[1] . PHP_EOL;
echo $nums[2] . PHP_EOL;
echo $nums[3] . PHP_EOL;
echo $nums[4] . PHP_EOL;
```

## 解説

### PHP の配列とは

PHP の配列は、Java と少し違う特徴がある:

- **動的配列**(可変長): Java の `ArrayList` のように、後から追加・削除できる
- **インデックス配列と連想配列が同じ型**: Java の `ArrayList` と `HashMap` が、PHP では同じ `array` 型
- **異なる型の値を混在できる**: `[1, "a", true]` のような書き方が可能(ただし業務では非推奨)

つまり、PHP の `array` は **「Java の ArrayList と HashMap を兼ねたようなもの」** と考えると良い。

### 配列リテラル

PHP では2種類の書き方がある:

```php
// 短縮構文(PHP 5.4+、推奨)
$nums = [10, 20, 30, 40, 50];

// 古い構文(後方互換のため残っている)
$nums = array(10, 20, 30, 40, 50);
```

**業務コードでは必ず短縮構文 `[]` を使う**。古い構文は legacy 系のコード以外では見かけない。

### インデックスアクセス

Java と全く同じ:

```php
$nums[0]  // 最初の要素(10)
$nums[4]  // 最後の要素(50)
```

- インデックスは **0始まり**(Java と同じ)
- `$nums[5]` のように範囲外を参照すると、警告を出して `null` を返す(Java の `ArrayIndexOutOfBoundsException` と違ってクラッシュしない)

### 範囲外アクセスの挙動(参考)

```php
$nums = [10, 20, 30];
echo $nums[10];  // Warning: Undefined array key 10
                 // 出力は何もなし(null が文字列化されて空文字)
```

PHP 8 から警告レベルが厳しくなったが、それでも例外にはならず処理は続行する。
**Java エンジニアから見ると「ゆるい」と感じるポイント**。後で学ぶ `array_key_exists` や `isset` で安全にアクセスする習慣をつけると良い。

## 別解

### `var_dump` でまとめて見る

```php
$nums = [10, 20, 30, 40, 50];
var_dump($nums);
```

実行結果:

```
array(5) {
  [0]=> int(10)
  [1]=> int(20)
  [2]=> int(30)
  [3]=> int(40)
  [4]=> int(50)
}
```

デバッグ時に配列の中身を確認する定番。今回の問題では「1行ずつ出力」が要件なので使えないが、参考までに。

### `print_r` で人間が読みやすく

```php
print_r($nums);
```

実行結果:

```
Array
(
    [0] => 10
    [1] => 20
    [2] => 30
    [3] => 40
    [4] => 50
)
```

### ループを使った書き方(S11以降で学ぶ)

```php
foreach ($nums as $num) {
    echo $num . PHP_EOL;
}
```

`foreach` を使えば、配列の長さに依存しない汎用的なコードになる。
実務では **ほぼこちらの形** を使う。

## Java との対比

### 配列宣言

| 観点 | Java | PHP |
|------|------|-----|
| 固定長配列 | `int[] nums = {10, 20, 30};` | (PHPには「固定長」の概念がない) |
| 可変長配列 | `List<Integer> nums = List.of(10, 20, 30);` | `$nums = [10, 20, 30];` |
| 型の混在 | できない(ジェネリクスで縛る) | できる(非推奨) |
| インデックス | `nums[0]` | `$nums[0]` |
| 長さ取得 | `nums.length` / `nums.size()` | `count($nums)` |

### 配列の長さを取る

```php
$nums = [10, 20, 30, 40, 50];
echo count($nums);  // → 5
```

Java の `nums.length` や `list.size()` に相当するのが PHP の `count()` 関数。
配列の長さは関数で取る、というのが PHP らしい(Java はメソッドやプロパティ)。

## つまずきやすいポイント

### 1. インデックスを 1 始まりだと勘違い

Java と同じく **0始まり**。最初の要素は `$nums[0]`。

### 2. 範囲外アクセスでもエラーにならない

```php
$nums = [10, 20];
echo $nums[10];  // 警告は出るが処理は続く、出力は空
```

Java なら例外でクラッシュするが、PHP は寛容。
**だからこそ、書く側が気をつける必要がある**。`isset($nums[10])` や `array_key_exists(10, $nums)` で事前チェックする習慣を。

### 3. 配列の長さを `length` で取ろうとする

```php
echo $nums->length;   // ← Java の癖、PHPでは動かない
echo $nums.length;    // ← JavaScript の癖、PHPでは "1" のように謎の出力に
echo count($nums);    // ← 正解
```

PHP では配列の長さは `count()` 関数で取る。

### 4. 文字列を配列としてアクセスできてしまう

```php
$str = "hello";
echo $str[0];  // → "h"
```

PHP では文字列も配列風にアクセスできる(C と同じ)。便利な場合もあるが、「配列だと思って書いていたら実は文字列だった」というバグの温床にもなる。
`is_array($var)` で判定するクセをつけると良い。

## 学習者の実装例

実際にこの問題を解いた際のコード例:

```php
<?php

$nums = [11, 22, 33, 44, 55];

echo $nums[0] . PHP_EOL;
echo $nums[1] . PHP_EOL;
echo $nums[2] . PHP_EOL;
echo $nums[3] . PHP_EOL;
echo $nums[4] . PHP_EOL;
```

→ 配列リテラル短縮構文を使い、インデックス 0〜4 を正しく順番にアクセス。
配列の値を `[11, 22, 33, 44, 55]` のように規則的にすることで、出力結果がインデックス順かを目視確認しやすい工夫がされている。
