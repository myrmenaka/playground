# PHP-B1-S9: 解説

## 解答コード

```php
<?php

$arr = [];

// パターン1: []= 演算子(末尾追加)
$arr[] = 10;
$arr[] = 20;

// パターン2: array_push 関数(複数同時追加)
array_push($arr, 30, 40);

// パターン3: += 演算子(未使用キーへの合体)
$arr += [4 => 50];

print_r($arr);
```

## 解説

### パターン1: `[]=` 演算子

```php
$arr[] = 10;
```

**配列の末尾に要素を追加する** 短縮構文。
PHP で **最も使われる追加方法**。

**メリット**:
- 短い、読みやすい
- 関数呼び出しのオーバーヘッドがない(わずかに高速)
- 既存の配列を直接変更する

**デメリット**:
- 一度に1つしか追加できない

### パターン2: `array_push` 関数

```php
array_push($arr, 30);
array_push($arr, 30, 40);  // 複数同時に追加可能
```

**メリット**:
- **一度に複数の要素を追加できる**
- 「何をしているか」が関数名から明確

**デメリット**:
- `[]=` より少しだけ遅い(関数呼び出しコスト)
- 1つ追加するだけなら `[]=` のほうがシンプル

**実務での使い分け**:
- 1つ追加 → `$arr[] = $value;`
- 複数追加 → `array_push($arr, $a, $b, $c);`

### パターン3: `+=` 演算子(配列の和)

```php
$arr = [10, 20];
$arr += [30, 40];   // [10, 20] のまま(0と1のキーが衝突するため)

$arr = [10, 20];
$arr += [2 => 30, 3 => 40];  // [10, 20, 30, 40](キーが衝突しないので追加される)
```

**`+=` は「追加」ではなく「配列の和(union)」**。挙動の特徴:

- 既存のキーがある場合、**左側の値が優先**(右側は無視)
- 既存のキーがない場合、右側の値が追加される

```php
$a = ['name' => 'Maru', 'age' => 28];
$b = ['age' => 99, 'email' => 'maru@example.com'];

$result = $a + $b;
// 結果: ['name' => 'Maru', 'age' => 28, 'email' => 'maru@example.com']
//                                  ^^
//                            $b の age 99 は無視される(左側が優先)
```

**実務での使い方**:
- インデックス配列の追加には **使わない**
- 連想配列のデフォルト値マージで稀に使う:
```php
  $config = $userConfig + $defaultConfig;
  // ユーザー設定優先、足りない設定はデフォルトで補う
```
- ただし最近は `array_merge` や **スプレッド演算子 `...`** を使うことが多い:
```php
  $config = [...$defaultConfig, ...$userConfig];  // スプレッド
  $config = array_merge($defaultConfig, $userConfig);  // 関数
```

## 別解

### `array_merge` で配列を結合

```php
$arr = [10, 20];
$arr = array_merge($arr, [30, 40, 50]);
// [10, 20, 30, 40, 50]
```

`+=` と違い、**インデックス配列を素直に結合できる**。インデックスは振り直される。

### スプレッド演算子(PHP 7.4+)

```php
$arr = [10, 20];
$arr = [...$arr, 30, 40, 50];
// [10, 20, 30, 40, 50]
```

JavaScript と同じ書き方。**モダンな PHP コードで増えてきている書き方**。

### 特定のインデックスに直接代入

```php
$arr = [];
$arr[5] = 100;  // インデックス5に直接代入
print_r($arr);
// Array ( [5] => 100 )  ← 0〜4 はスキップされる
```

これは「追加」というより「特定インデックスへの代入」。インデックスが飛び石になる点に注意。

## 4つの方法の比較

| 方法 | 書き方 | 速度 | 用途 |
|------|--------|------|------|
| `[]=` | `$arr[] = $val;` | 最速 | 1つ追加(最頻出) |
| `array_push` | `array_push($arr, $a, $b);` | やや遅い | 複数同時追加 |
| `array_merge` | `$arr = array_merge($arr, $other);` | 普通 | 配列同士の結合 |
| スプレッド `...` | `$arr = [...$arr, ...$other];` | 普通 | モダンな結合(PHP 7.4+) |
| `+=` | `$arr += $other;` | 速い | 連想配列のデフォルト値マージ |

## Java との対比

| Java | PHP |
|------|-----|
| `list.add(10);` | `$arr[] = 10;` |
| `list.add(10); list.add(20);` | `array_push($arr, 10, 20);` |
| `list1.addAll(list2);` | `$arr = array_merge($arr, $other);` |
| (Java にはない) | `$arr += $other;` |
| (Java にはない直感的な構文) | `$arr = [...$arr, ...$other];` |

PHP は配列操作のバリエーションが豊富。Java の `ArrayList` よりも機能が多い反面、**どれを使うかの判断が必要**。

## つまずきやすいポイント

### 1. `array_push` の戻り値を勘違いする

```php
$arr = [];
$result = array_push($arr, 10);
// $result は「追加後の要素数」(= 1)
// 「追加された配列」を返すと思いがちだが違う
```

- **`array_push` は元の配列を直接変更する**(参照渡し)
- 戻り値は**新しい要素数**

なので、こう書くと配列が消える:

```php
$arr = array_push($arr, 10);  // ❌ $arr が 1(数値)になってしまう
```

正しくは:

```php
array_push($arr, 10);  // ✅ 戻り値は使わない
```

**この罠を避けるためにも、業務では `[]=` のほうが安全**。

### 2. `+=` で「追加されない」現象

```php
$arr = [10, 20];
$arr += [30, 40];
print_r($arr);
// Array ( [0] => 10 [1] => 20 )  ← 30, 40 は追加されない!
```

これは PHP 初学者が **必ず引っかかる罠**。
原因: `[30, 40]` は内部的に `[0 => 30, 1 => 40]` であり、既に `$arr` の 0 と 1 が使われているため。

**追加したいなら `array_merge` か `[]=` を使う**:

```php
$arr = [10, 20];
$arr = array_merge($arr, [30, 40]);  // ✅ [10, 20, 30, 40]
```

### 3. 連想配列に対して `array_push` を使う

```php
$user = ['name' => 'Maru'];
array_push($user, 28);
// 結果: ['name' => 'Maru', 0 => 28]
//                          ^^
//                  数値キー 0 で追加される
```

`array_push` は **数値キーで末尾に追加** する関数。連想配列に使うとキーが意図しない数値になる。
連想配列にキーを指定して追加するなら:

```php
$user = ['name' => 'Maru'];
$user['age'] = 28;  // ✅
```

### 4. 「追加」と「結合」を混同する

| 操作 | やりたいこと | 適切な方法 |
|------|------------|----------|
| 1つの値を追加 | `[1, 2]` に `3` を追加 → `[1, 2, 3]` | `$arr[] = 3;` |
| 配列同士を結合 | `[1, 2]` と `[3, 4]` を合体 → `[1, 2, 3, 4]` | `array_merge` または スプレッド |

「追加」の感覚で `+=` を使うと罠にハマる。

## 実務での使用頻度

業務コード(Laravel等)で見る頻度:

```
$arr[] = $value;              ★★★★★ 圧倒的に多い
array_merge($a, $b)           ★★★★☆ 配列の結合で頻出
[...$a, ...$b](スプレッド)    ★★★☆☆ モダンコードで増加
array_push                    ★★☆☆☆ 複数同時追加で稀に
+= 演算子                     ★☆☆☆☆ ほぼ見ない
```

**結論**: `[]=` を最優先で覚える。他は「読めれば良い」程度でOK。

## 学習者の実装例

実際にこの問題を解いた際のコード例:

```php
<?php

$array = [];

$array[] = 1;
array_push($array, 2, 3);
$array += [3 => 4, 4 => 5];

print_r($array);
```

→ 3パターンを正しく使い分け、最終的に5要素の配列を作成できている。
特に `+=` の挙動を理解した上で、**未使用キー(3 と 4)を明示的に指定** している点が秀逸。
ただし業務では `+=` でこの書き方をすることはほぼなく、`[]=` か `array_merge` が主流。
