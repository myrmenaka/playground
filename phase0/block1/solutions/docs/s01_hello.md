# PHP-B1-S1: 解説

## 解答コード

```php
<?php

echo "Hello, World!" . PHP_EOL;
```

## 実行方法

```bash
php s01_hello.php
```

## 解説

### `<?php` タグ

PHP ファイルは必ず `<?php` で始める。終了タグ `?>` は省略するのが推奨(理由: ファイル末尾に余計な空白や改行が入ると、後の処理で意図しない出力につながるため)。

### `echo`

文字列を出力する命令。Java の `System.out.print` に相当(改行なし版)。
複数の引数をカンマで渡すこともできる:

```php
echo "Hello", ", ", "World!", PHP_EOL;
```

### `.` 演算子

PHP の文字列連結演算子。Java の `+` に相当する。
PHP では `+` は数値演算専用なので、文字列連結に使うとエラーになる(または意図しない結果になる)。

### `PHP_EOL`

環境依存の改行コードを表す定数。
- Linux / macOS: `\n`
- Windows: `\r\n`

学習中はファイルを WSL 上で扱うので `"\n"` でも実質同じだが、可搬性を考えて `PHP_EOL` を使う癖をつけておくと良い。

## 別解

```php
<?php

// パターン1: ダブルクォート内に \n を埋め込む
echo "Hello, World!\n";

// パターン2: print を使う(echo とほぼ同じだが式として値を返す)
print "Hello, World!" . PHP_EOL;

// パターン3: 終了タグを使う(非推奨だが見かけることはある)
?>Hello, World!
```

## Java との対比

| 観点 | Java | PHP |
|------|------|-----|
| 出力命令 | `System.out.print()` | `echo` |
| 文字列連結 | `+` | `.` |
| ファイル開始 | `class` 宣言など | `<?php` |
| 改行付き出力 | `System.out.println()` | `echo "..." . PHP_EOL;` |

## つまずきやすいポイント

- **`<?php` を書き忘れる**: PHP として解釈されず、ただのテキストファイル扱いになる
- **`+` で文字列を連結しようとする**: Java の癖で `"a" + "b"` と書きがち。PHP では `.` を使う
- **改行を忘れる**: 出力が次のシェルプロンプトとくっついて見える(動作には影響なし)
