# PHP-B1-S4: 解説

## 解答コード

```php
<?php

$name = "Maru";
$age = 28;

echo <<<EOT
私は{$name}です。{$age}歳です。
EOT;

echo PHP_EOL;
```

## 解説

### ヒアドキュメントとは

複数行にわたる文字列を、エスケープなしで素直に書ける構文。
PHP では2種類ある:

| 種類 | 開始タグ | 変数展開 | 用途 |
|------|---------|---------|------|
| **Heredoc**(ヒアドキュメント) | `<<<EOT` | する | ダブルクォート相当 |
| **Nowdoc**(ナウドキュメント) | `<<<'EOT'` | しない | シングルクォート相当 |

`EOT` は識別子で、慣習的によく使われるが任意の英大文字でOK(`HTML`、`SQL`、`MSG` など)。

### 構文の重要ルール

1. **開始タグの後ろは改行する**(`<<<EOT` の直後に改行)
2. **終了タグは行頭から書く**(PHP 7.2 までは行頭必須)
3. **終了タグの後ろにセミコロン `;` を付ける**(式として終わる)
4. **PHP 7.3 以降はインデント可能**(終了タグのインデントが文字列の左端になる)

### PHP 7.3+ のインデント可能な書き方

```php
$message = <<<EOT
    私は{$name}です。
    {$age}歳です。
    EOT;
```

`EOT;` のインデント(スペース4個)が「左端」とみなされ、各行から自動的に取り除かれる。
ただし学習中は **行頭に揃える書き方** で覚えるのが安全。

## 別解

### Nowdoc(変数展開しない)

```php
echo <<<'EOT'
私は{$name}です。{$age}歳です。
EOT;
// → 私は{$name}です。{$age}歳です。  ※そのまま出力
```

開始タグの識別子をシングルクォートで囲むと Nowdoc になる。
リテラルなテンプレート(SQL のひな形、HTMLのテンプレ)を書くときに便利。

### 改行を含むヒアドキュメント

```php
echo <<<EOT
こんにちは、{$name}さん。
あなたは{$age}歳ですね。
今後ともよろしくお願いします。
EOT;
```

これがヒアドキュメントの本領。複数行の文字列を素直に書ける。
`echo` でこの結果をそのまま出力すれば、改行もそのまま反映される。

## いつヒアドキュメントを使うか

業務でよく見かけるユースケース:

1. **複数行のメール本文**を組み立てる時
2. **SQL のひな形**を書く時(ただし Eloquent で書くのが基本)
3. **HTML テンプレート**を生成する時(ただし Blade で書くのが基本)
4. **ログのメッセージ**を整形する時

```php
// メール本文の例
$body = <<<EOT
{$user->name} 様

ご注文ありがとうございます。
注文番号: {$order->id}
合計金額: {$order->total}円

引き続きよろしくお願いいたします。
EOT;
```

## Java との対比

Java にもヒアドキュメント相当の機能があるが、**Java 13 以降のテキストブロック**がそれにあたる:

```java
// Java 13+ のテキストブロック
String message = """
    私は%sです。%d歳です。
    """.formatted(name, age);
```

| 言語 | 構文 | 変数展開 |
|------|------|---------|
| PHP Heredoc | `<<<EOT ... EOT;` | する |
| PHP Nowdoc | `<<<'EOT' ... EOT;` | しない |
| Java テキストブロック | `""" ... """` | しない(`String.format` 等で別途処理) |
| JavaScript テンプレートリテラル | `` `...${var}...` `` | する(`${var}` 形式) |

PHP のヒアドキュメントは「変数を埋め込める」点で JavaScript のテンプレートリテラルに近い感覚。

## つまずきやすいポイント

### 1. 終了タグの後ろに余計な文字がある

```php
echo <<<EOT
hello
EOT ;  // ← 半角スペースが入っているとパースエラー
```

PHP 7.3+ なら多少緩和されたが、**`EOT;` だけを行頭に書く**のが安全。

### 2. 終了タグの前後に改行がない

```php
echo <<<EOT
hello EOT;  // ← 同じ行に書くと文字列の一部とみなされる
```

終了タグは必ず **行の先頭** に独立して書く。

### 3. ヒアドキュメント自体に改行は付かない

```php
echo <<<EOT
hello
EOT;
// → "hello" の後に改行はあるが、ターミナルでは次のプロンプトに続く
```

末尾に改行を入れたければ、ヒアドキュメントの中で意図的に改行するか、後で `PHP_EOL` を追加する。
解答コードでは `echo PHP_EOL;` を別途呼んでいる。

### 4. インデントが文字列に含まれてしまう(PHP 7.2 以前のスタイル)

```php
$message = <<<EOT
    hello
EOT;
// → "    hello" になる(スペース4個が文字列に含まれる)
```

PHP 7.3+ なら終了タグのインデント分が自動で除去されるが、古い書き方の癖で混乱しないよう注意。

## 補足: 実務での頻度

正直に言うと、**業務コードでヒアドキュメントを目にする頻度は高くない**:
- メールやログは Mailable / Logger を使うことが多い
- HTML は Blade、SQL は Eloquent / Query Builder を使う

ただし「あ、これヒアドキュメントだ」と読めることは大事。CMS のテンプレートやマイグレーションの SQL 直書きで遭遇する。
