# PHP-B1-S3: 解説

## 解答コード(推奨)

```php
<?php

$name = "Maru";
$age = 28;

echo "私は{$name}です。{$age}歳です。" . PHP_EOL;
```

## 解説

### ダブルクォート内の変数展開

PHP では **ダブルクォート文字列** の中に変数を直接書くと、その変数の値に置き換わる。これを「変数展開」と呼ぶ。

```php
$name = "Maru";
echo "私は{$name}です";  // → 私はMaruです
```

これは Java にはない PHP の特徴的な機能(JavaScript のテンプレートリテラル `` `${name}` `` に近い)。

### `{$変数名}` と `$変数名` の違い

実は波括弧なしでも動く:

```php
echo "私は$nameです";  // → 私はMaruです
```

しかし、以下の理由で **波括弧で囲む書き方が推奨される**:

1. **変数の境界が明確になる**
```php
   echo "$nameさん";   // → 動くが境界が分かりにくい
   echo "{$name}さん"; // → 推奨
```

2. **配列要素やオブジェクトプロパティを埋め込む時に必須**
```php
   echo "ユーザー名: {$user['name']}";       // 配列
   echo "ユーザー名: {$user->name}";         // オブジェクト
```

3. **チームコードで一貫性が保てる**

### シングルクォートとの違い(超重要)

PHP では **シングルクォートは変数展開しない**:

```php
echo '私は{$name}です';  // → 私は{$name}です  ※そのまま出力される
echo "私は{$name}です";  // → 私はMaruです
```

| クォート | 変数展開 | エスケープ | 速度 |
|---------|---------|----------|------|
| `' '`(シングル) | しない | `\'` `\\` のみ | わずかに速い |
| `" "`(ダブル) | する | `\n` `\t` などフル対応 | わずかに遅い |

**使い分けの目安**:
- 変数を埋め込むとき → ダブルクォート `"..."`
- 静的な文字列のみ → シングルクォート `'...'`(意図が明確になる)

## 別解(3パターン)

S5 で扱う「文字列の中に変数を埋め込む3パターン」を先取りで紹介。

### パターン1: 連結演算子 `.`

```php
echo "私は" . $name . "です。" . $age . "歳です。" . PHP_EOL;
```

- 一番原始的な書き方
- 連結が増えると見づらくなる

### パターン2: 変数展開(推奨・解答コード)

```php
echo "私は{$name}です。{$age}歳です。" . PHP_EOL;
```

- 短く読みやすい
- 業務コードでも頻出

### パターン3: `sprintf` / `printf`

```php
echo sprintf("私は%sです。%d歳です。", $name, $age) . PHP_EOL;
// または
printf("私は%sです。%d歳です。" . PHP_EOL, $name, $age);
```

- C や Java の `String.format` 相当
- フォーマット指定子(`%s`、`%d` など)で型を明示できる
- 数値のフォーマット(桁数・小数点)などを細かく指定できる
- ログ出力などで好まれる

```php
// %d は整数、%s は文字列、%05d は5桁0埋め整数、%.2f は小数点2桁
echo sprintf("ID: %05d, 名前: %s, 評価: %.2f", 42, "Maru", 3.14159) . PHP_EOL;
// → ID: 00042, 名前: Maru, 評価: 3.14
```

## Java との対比

| Java | PHP |
|------|-----|
| `"私は" + name + "です"` | `"私は" . $name . "です"` |
| `String.format("私は%sです", name)` | `sprintf("私は%sです", $name)` |
| (テンプレート文字列なし、Java 21+ で String Templates 検討中) | `"私は{$name}です"` |

PHP の変数展開は、Java エンジニアから見ると「便利だな」と感じるポイント。

## つまずきやすいポイント

- **シングルクォートで書いて変数が展開されない**: `'私は$nameです'` → そのまま出力されてしまう
- **連結の `.` の前後にスペースを入れ忘れる**: 動くが読みにくい。`echo "a" . "b"` のように間にスペースを入れる
- **`+` で連結しようとする**: Java の癖。PHP では `+` は数値演算なのでエラーまたは想定外の動作

## 学習者の実装例

実際にこの問題を解いた際のコード例:

```php
<?php

$name = "Maruyama";
$age = 33;

echo "私は{$name}です。{$age}歳です。" . PHP_EOL;
```

→ **変数展開 `{$name}` を使い、`PHP_EOL` で改行**。最初の自力Stepでこの書き方ができていれば、十分良いスタート。
