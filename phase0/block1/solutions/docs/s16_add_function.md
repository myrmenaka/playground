# S16 解説: 2つの数を足す関数

## ポイント

### 関数定義の基本構文

```php
function 関数名(引数1, 引数2, ...) {
    // 処理
    return 戻り値;
}
```

- `function` キーワードで関数を定義
- 関数名は慣習的に**スネークケース**(`my_function`)または**キャメルケース**(`myFunction`)
- 引数は `$` 付きの変数として宣言
- 戻り値を返す場合は `return` を使う

### 関数の呼び出し

```php
$result = add(3, 5);    // 戻り値を変数に入れる
echo add(3, 5);         // 戻り値を直接使う
add(3, 5);              // 戻り値を捨てる(今回は無意味)
```

Java とほぼ同じ感覚で呼び出せる。

### スペーシングの慣習(PSR-12)

PHP のコーディング規約 PSR-12 では、関数定義と呼び出しのスペーシングが定められている。

[参考:PSR-12まとめ：PHPコーディングスタイルの標準化](https://qiita.com/t1k2a/items/bc129da936a833658007)

```php
function add($a, $b) {        // ⭕ 関数名と ( の間にスペースなし
    return $a + $b;
}

add(3, 5);                    // ⭕ 同上

function add ($a, $b) {       // △ 動くが PSR-12 違反
add (3, 5);                   // △ 同上
```

| 場所 | 慣習 |
|------|------|
| `function` と関数名の間 | スペースあり |
| 関数名と `(` の間 | スペース**なし** |
| 引数のカンマの後 | スペースあり |
| `)` と `{` の間 | スペースあり |

Laravel をはじめ、ほとんどの PHP プロジェクトはこの規約に従っている。エディタ(VSCode + Intelephense)が自動整形してくれることも多いので、最初は気にしすぎなくてもよい。

## 別解

### return を省略する書き方(NG)

```php
function add($a, $b) {
    $a + $b;   // ❌ 計算しているが返していない
}

echo add(3, 5);   // 何も出力されない(NULLが返る)
```

PHP では `return` を書かないと `null` が返る。Java のように「戻り値の型が指定されていれば return 必須」という強制はない(動的型付けの宿命)。**必ず `return` を書く習慣**をつけたい。

### アロー関数(短い無名関数、PHP 7.4+)

```php
$add = fn($a, $b) => $a + $b;

echo $add(3, 5) . PHP_EOL;
```

簡単な処理なら、関数を変数に入れる「アロー関数」で書ける。配列操作(`array_map` など)で重宝する書き方。Laravel のコレクション操作で頻出する。今は「こんな書き方もある」と知っておく程度でOK。

### 名前付き引数(PHP 8.0+)

```php
function add($a, $b) {
    return $a + $b;
}

echo add(a: 3, b: 5) . PHP_EOL;   // 引数名を明示して呼び出す
```

引数名を指定して呼び出せる。引数の順序を気にしなくてよくなる、可読性が上がるなどの利点がある。Laravel でも使われ始めている。

## つまずきやすい点

### 1. PHP の関数は「関数スコープ」を持つ

```php
$x = 10;

function show() {
    echo $x;   // ❌ Notice: Undefined variable
}

show();
```

PHPの関数の中からは、外で定義した変数に**直接アクセスできない**。Java の static メソッドが他のフィールドに直接アクセスできないのに似ている。

外の変数を使いたい場合は、引数で渡すのが基本(後のStepで詳しく扱う)。

### 2. 関数名は大文字小文字を区別しない(意外な落とし穴)

```php
function add($a, $b) { return $a + $b; }

echo add(3, 5);   // 8
echo Add(3, 5);   // 8(動く!)
echo ADD(3, 5);   // 8(動く!)
```

PHPでは関数名の大文字小文字は区別されない。ただし**慣習として小文字始まりのキャメルケース or スネークケース**で書く。混在させると読みにくくなるだけなので、定義したまま呼ぶのが基本。

### 3. 同じ関数を2回定義するとエラー

```php
function add($a, $b) { return $a + $b; }
function add($a, $b) { return $a * $b; }   // ❌ Fatal error: Cannot redeclare
```

Java のオーバーロード(同名で引数違い)も**PHPには存在しない**。後のStepで型宣言を学ぶが、それでも「引数の数や型が違うから別関数」という扱いはできない。引数の違いを吸収したい場合は**引数のデフォルト値**や**可変長引数**で対応する。

## Java との対比

```java
// Java
public class Main {
    public static int add(int a, int b) {
        return a + b;
    }
    
    public static void main(String[] args) {
        System.out.println(add(3, 5));
        System.out.println(add(10, 20));
    }
}
```

```php
// PHP
function add($a, $b) {
    return $a + $b;
}

echo add(3, 5) . PHP_EOL;
echo add(10, 20) . PHP_EOL;
```

| 観点 | Java | PHP |
|------|------|-----|
| 関数の定義場所 | クラス内のメソッドとして定義 | トップレベルに直接定義可 |
| 修飾子 | `public static` などが必要 | 不要 |
| 引数の型 | 必須 | 任意(次のStepで追加) |
| 戻り値の型 | 必須(`int`, `void` など) | 任意(次のStepで追加) |
| オーバーロード | あり | なし |
| 関数の呼び出し | `クラス名.add()` または `add()`(同クラス内) | 直接 `add()` |

**PHPの関数はJavaのメソッドより「気軽」に定義できる**。トップレベルにポンと書けるので、簡単な処理を関数化するハードルが低い。一方で、規模が大きくなるとクラスにまとめる方が管理しやすくなるため、Laravel ではクラスのメソッドとして書くことが圧倒的に多い。

ただし「ヘルパー関数」と呼ばれる便利関数(Laravel の `auth()`, `route()`, `dd()` など)はトップレベル関数として実装されている。**「関数を素朴に定義して呼ぶ」感覚を、まずここでしっかり身につけておく**ことが、その後の関数型的な処理(`array_map`, `array_filter` など)の理解にも繋がる。
