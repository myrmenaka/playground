# PHP-B1-S6: インデックス配列を全部出力

## 概要

PHP の配列(インデックス配列)の基本を体験する。

## 学習目的

- インデックス配列の作り方を覚える(`[]` 短縮構文)
- 配列の要素にインデックスでアクセスできる
- 配列の要素を1つずつ出力できる

## 問題

数値5個を格納したインデックス配列を作成し、すべての要素を1行ずつ出力するプログラムを書いてください。

## 制約

- 配列リテラル `[1, 2, 3, ...]` 形式で配列を宣言すること
- 配列には任意の整数を5個格納すること
- 各要素を1行ずつ出力すること(末尾に改行)
- **`foreach` や `for` などのループは使わない**(S11 以降で扱うため、ここではインデックスで個別アクセス)

## 入力

なし(配列に直接値を代入する)

## 出力例

配列が `[10, 20, 30, 40, 50]` の場合:

```
10
20
30
40
50
```

## ファイル名

`my_answers/s06_index_array.php`

## ヒント(必要な時だけ)

<details>
<summary>クリックして表示</summary>

- 配列宣言: `$nums = [10, 20, 30, 40, 50];`
- インデックスアクセス: `$nums[0]` で1つ目の要素を取得(0始まり)
- Java の `int[] nums = {10, 20, 30, 40, 50};` と同じ感覚
- 5回 `echo` を書いて、それぞれ違うインデックスを指定する

</details>

## 進め方

1. `my_answers/s06_index_array.php` を作成
2. 自分で考えて書く
3. 動かして5行出力されるか確認
4. 詰まったらヒントを見る → それでも詰まったら「答え見せて」と言う

## 補足

ループを使わない縛りは、**配列のインデックス指定での個別アクセスを体感する**ためです。
ループはこの後の Step(S11〜S13)で扱います。
