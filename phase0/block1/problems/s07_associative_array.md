# PHP-B1-S7: 連想配列を全部出力

## 概要

PHP の連想配列(キーと値のペアで管理する配列)の基本を体験する。

## 学習目的

- 連想配列の作り方を覚える(`['key' => 'value']`)
- キーで値にアクセスできる
- インデックス配列との違いを体感する

## 問題

ユーザー1人分の情報(名前、年齢、メールアドレス)を連想配列に格納し、すべての要素を「キー: 値」の形式で1行ずつ出力するプログラムを書いてください。

## 制約

- 連想配列リテラル `['key' => 'value']` 形式で配列を宣言すること
- キーは以下の3つを使うこと: `name`(string)、`age`(int)、`email`(string)
- 各要素を「キー: 値」の形式で1行ずつ出力すること(末尾に改行)
- **`foreach` などのループは使わない**(キーを直接指定してアクセス)

## 入力

なし(配列に直接値を代入する)

## 出力例

```
name: Maru
age: 28
email: maru@example.com
```

## ファイル名

`my_answers/s07_associative_array.php`

## ヒント(必要な時だけ)

<details>
<summary>クリックして表示</summary>

- 連想配列宣言: `$user = ['name' => 'Maru', 'age' => 28, 'email' => 'maru@example.com'];`
- キーアクセス: `$user['name']` で `'name'` キーの値を取得
- Java の `HashMap<String, Object>` と同じ感覚(`map.get("name")` に相当)
- 出力には連結 `.` か変数展開 `{$user['name']}` のどちらでも可

</details>

## 進め方

1. `my_answers/s07_associative_array.php` を作成
2. 自分で考えて書く
3. 動かして3行出力されるか確認
4. 詰まったらヒントを見る → それでも詰まったら「答え見せて」と言う

## 補足

ループを使わない縛りは、**キー指定での個別アクセスを体感する**ためです。
ループでまとめて処理するのは S11 以降で扱います。
