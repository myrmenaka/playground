# PHP-B1-S4: ヒアドキュメントで自己紹介

## 概要

ヒアドキュメント(Heredoc)を使った文字列の書き方を体験する。複数行の文字列を扱う時の定番構文。

## 学習目的

- ヒアドキュメント `<<<EOT ... EOT;` の書き方を覚える
- ダブルクォート相当(変数展開される)の挙動を確認する
- Nowdoc(`<<<'EOT'`)との違いを知る

## 問題

S3 で書いた自己紹介プログラムを、ヒアドキュメントを使って書き直してください。
出力結果は S3 と同じになります。

## 制約

- 文字列の組み立てに **ヒアドキュメント** を使うこと
- 開始タグは `<<<EOT`、終了タグは `EOT;` を使うこと
- 名前(string)と年齢(int)を変数に格納し、ヒアドキュメント内に変数展開で埋め込むこと

## 入力

なし(変数に直接代入する)

## 出力例

```
私はMaruです。28歳です。
```

## ファイル名

`s04_heredoc.php`

## 進め方

1. 解答を見ながら写経する
2. ファイルを閉じて、何も見ずに再現
3. 動かして S3 と同じ出力になるか確認
4. 余裕があれば、複数行のメッセージにアレンジしてみる
