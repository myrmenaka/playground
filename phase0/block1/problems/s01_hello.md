# PHP-B1-S1: Hello, World!

## 概要

PHP の最初の一歩。`echo` を使った文字列出力を体験する。

## 学習目的

- PHP ファイルの基本構造(`<?php` で始める)を知る
- `echo` での文字列出力ができる
- `PHP_EOL` で改行を扱う

## 問題

`Hello, World!` という文字列を出力するプログラムを作成してください。

## 制約

- `echo` を使うこと
- 出力末尾に改行を含めること
- 改行には `PHP_EOL` を使うこと

## 入力

なし

## 出力例

```
Hello, World!
```

## ファイル名

`s01_hello.php`

## 進め方

1. 上の要件を見ながら、自分で書いてみる(写経Stepなので、解答を見ながらでもOK)
2. ファイルを閉じて、何も見ずにもう一度書く
3. ターミナルで `php s01_hello.php` を実行して、期待通り出力されることを確認
