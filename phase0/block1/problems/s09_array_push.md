# PHP-B1-S9: 配列に値を追加する3パターン

## 概要

PHP の配列に値を追加する代表的な方法を3つ覚える。状況によって使い分けられるようになる。

## 学習目的

- インデックス配列に値を追加する3つの方法を覚える
- それぞれの違い(構文、用途)を体感する
- どの方法がいつ使われるか分かる

## 問題

空のインデックス配列を作成し、3つの異なる方法で値を追加して、最終的に5つの要素を持つ配列を作るプログラムを書いてください。
追加が完了したら、配列全体を `print_r` で出力すること。

## 制約

- 最初は **空の配列** で宣言すること(`$arr = [];`)
- 以下の3つすべてのパターンを使って値を追加すること:
  - **パターン1**: `[]=` 演算子(短縮構文)
  - **パターン2**: `array_push` 関数
  - **パターン3**: `+=` 演算子(配列の和) ※ **重要: これは特殊な挙動をするので、ヒント参照**
- 最終的に配列の要素数は5個になっていること
- 最後に `print_r` で配列の中身を出力すること

## 入力

なし(配列に直接値を追加する)

## 出力例

最終的に配列が `[10, 20, 30, 40, 50]` になる場合:

```
Array
(
    [0] => 10
    [1] => 20
    [2] => 30
    [3] => 40
    [4] => 50
)
```

### パターン1: `[]=` 演算子

```php
$arr[] = 10;  // 末尾に追加
$arr[] = 20;
```

### パターン2: `array_push` 関数

```php
array_push($arr, 30);          // 末尾に1つ追加
array_push($arr, 40, 50);      // 末尾に複数同時に追加もできる
```

### パターン3: `+=` 演算子(注意が必要)

`+=` は **インデックス配列の追加には向いていない** 演算子です。連想配列の合体用と考えてください。
インデックス配列で使うと、**既存のキーの値は上書きされない**ため、追加されない可能性があります。

```php
$arr = [10, 20];
$arr += [30, 40];   // 期待:[10, 20, 30, 40]、実際: [10, 20]のまま!

// 連想配列なら期待通り動く
$user = ['name' => 'Maru'];
$user += ['age' => 28];  // ['name' => 'Maru', 'age' => 28]
```

この問題では「3パターンすべてを使う」ことが目的なので、**`+=` は連想配列の合体例として使ってもOK**、または `+=` の挙動を確認するためにあえて期待外れの挙動を見ても良い、とします。

**3パターンの組み合わせ例**:
- パターン1で2個追加(配列に2要素になる)
- パターン2で2個追加(配列に4要素になる)
- パターン3で1個追加(配列に5要素になる)

`+=` で1要素追加するには、**まだ存在しないキー** に対する追加なら成功します:

```php
$arr = [10, 20, 30, 40];
$arr += [4 => 50];  // インデックス4は未使用なので追加される
```

## 補足

`+=` は実務で **インデックス配列の追加に使うことはほぼない** 演算子です。
ただし「他人のコードで見かけた時に何をしているか分かる」ようになることが目的。
実務での主流は **パターン1(`[]=`)**、次に **パターン2(`array_push`)**。
