# S14: 偶数・奇数の判定

数値を1つ受け取り、偶数なら「偶数」、奇数なら「奇数」と出力するプログラムを書いてください。

## 制約

- `if` / `else` を使うこと(`match` や三項演算子は次のStepで扱うので使わない)
- 判定対象の数値は変数に代入してから使うこと
- 変数の値を変えれば判定結果が変わるように書くこと
- 出力には `echo` を使うこと

## 入力

なし(変数に直接代入)

## 出力例

`$num = 10` の場合:
```
偶数
```

`$num = 7` の場合:
```
奇数
```

## ファイル名

`my_answers/s14_if_even_odd.php`

<details>
<summary>クリックで表示</summary>

- `if` の条件式は `()` で囲む
- 比較演算子は `==`(等しい)を使う(PHPには `===` もあるが、今回はどちらでも動く)
