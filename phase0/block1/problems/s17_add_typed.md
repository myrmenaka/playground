# S17: 型宣言付きの加算関数

S16 で書いた `add` 関数に、引数と戻り値の型宣言を追加してください。
さらに、ファイル先頭で **strict types** を有効化してください。

## 進め方

このStepは**写経Step**です。

1. `solutions/s17_add_typed.php` を見ながら写経する
2. 動作確認後、ファイルを閉じて何も見ずに再現する
3. 余裕があれば、文字列を引数で渡してみて(例: `add("3", 5)`)エラーが出ることを確認する

## 仕様

- ファイル先頭で `declare(strict_types=1);` を宣言する
- 引数 `$a`, `$b` の型を `int` と宣言する
- 戻り値の型を `int` と宣言する
- 関数を呼び出して結果を出力する

## 出力例

```
8
30
```

## 動作確認(余裕があれば)

写経で動作確認後、以下のように文字列を渡すとどうなるか試してみてください。

```php
echo add("3", 5);   // strict_types が有効なら TypeError
```
