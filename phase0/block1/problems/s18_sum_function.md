# S18: 配列の合計を返す関数

整数の配列を受け取り、その合計値を返す関数 `sum` を定義してください。

## 制約

- ファイル先頭で `declare(strict_types=1);` を宣言すること
- 関数名は `sum` とすること
- 引数は1つで、配列を受け取る(型宣言 `array` を付けること)
- 戻り値の型は `int` を宣言すること
- 関数内では `foreach` などのループを使って合計を計算すること(`array_sum` などの組み込み関数は使わない)
- 動作確認のため、関数を2回以上呼び出して結果を出力すること

## 入力

なし(関数呼び出し時に直接配列を渡す)

## 出力例

`sum([1, 2, 3, 4, 5])` を呼び出した場合:
```
15
```

`sum([10, 20, 30])` を呼び出した場合:
```
60
```
