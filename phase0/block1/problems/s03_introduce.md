# PHP-B1-S3: 自己紹介プログラム

## 概要

変数に格納した値を使って、決められた形式の文字列を出力する。最初の自力Step。

## 学習目的

- 変数の値を文字列の中に埋め込む方法を身につける
- 文字列の連結 or 変数展開を使い分けられるようになる

## 問題

あなたはユーザー情報を表示する自己紹介プログラムを開発しています。指定された変数を用意し、決められた形式で出力するプログラムを作成してください。

## 制約

- 名前を格納する変数は文字列型(string)
- 年齢を格納する変数は整数型(int)
- 出力は1行で、末尾に改行を含めること
- 出力形式: `私は{名前}です。{年齢}歳です。`

## 入力

なし(変数に直接代入する)

## 出力例

名前が `Maru`、年齢が `28` の場合:

```
私はMaruです。28歳です。
```

## ファイル名

`s03_introduce.php`

## 進め方

1. 自分で考えて書く(解答は見ない)
2. 動かして期待通りの出力か確認
3. 詰まったらヒントを見る → それでも詰まったら解答を見る
4. 解答を見たら、ファイルを閉じて何も見ずに書き直す

## ヒント(必要な時だけ)

<details>
<summary>クリックして表示</summary>

- 文字列の連結には `.` を使う
- または、ダブルクォート内に `"{$変数名}"` で変数を埋め込む方法もある
- 改行には `PHP_EOL` を使う
