# S16: 2つの数を足す関数

2つの数値を受け取り、その合計を返す関数 `add` を定義してください。
定義した関数を実際に呼び出して、結果を出力するところまで書いてください。

## 制約

- 関数名は `add` とすること
- 引数は2つ(`$a` と `$b`)
- 戻り値は2つの引数の合計
- 型宣言はまだ書かなくてOK(次のStep S17 で追加します)
- 関数を呼び出した結果を `echo` で出力すること

## 入力

なし(関数呼び出し時に直接値を渡す)

## 出力例

`add(3, 5)` を呼び出した場合:
```
8
```

`add(10, 20)` を呼び出した場合:
```
30
```

## ファイル名

`my_answers/s16_add_function.php`

## ヒント

<details>
<summary>クリックで表示</summary>

- 関数定義の構文は `function 関数名(引数1, 引数2) { ... }`
- 関数から値を返すには `return` を使う(Java と同じ)
- 関数を呼び出すには `add(3, 5)` のように書く
- 呼び出した結果は変数に入れてもいいし、直接 `echo` に渡してもよい
