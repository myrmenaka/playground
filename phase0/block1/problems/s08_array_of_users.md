# PHP-B1-S8: 連想配列の配列(ユーザー3人分)

## 概要

連想配列を要素として持つ配列を扱う。業務でよく見る「DBから取得した複数件のデータ」をイメージした構造。

## 学習目的

- 多次元配列(配列の配列)の作り方を覚える
- ネストした配列へのアクセス方法を覚える
- インデックスとキーの組み合わせアクセス `$users[0]['name']` ができる

## 問題

ユーザー3人分の情報(名前、年齢)を持つ配列を作成し、全員の名前を1行ずつ出力するプログラムを書いてください。

## 制約

- 外側はインデックス配列、内側は連想配列(`name`、`age`)とすること
- ユーザーは3人分作成すること
- 全員の名前を1行ずつ出力すること(末尾に改行)
- **`foreach` などのループは使わない**(インデックス指定で個別アクセス)

## 入力

なし(配列に直接値を代入する)

## 出力例

```
Maru
Akane
Taro
```

## ファイル名

`s08_array_of_users.php`

## 進め方

1. 解答を見ながら写経する
2. ファイルを閉じて、何も見ずに再現
3. 動かして3行出力されるか確認
4. 余裕があれば名前以外の情報も出してみる
