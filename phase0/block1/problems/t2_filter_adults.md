# T2: 成人ユーザーの名前を抽出する関数

ユーザー情報(`name` と `age`)の連想配列を要素に持つ配列を受け取り、**20歳以上のユーザーの `name` だけ**を集めた配列を返す関数 `filterAdultNames` を書いてください。

## 制約

- ファイル先頭で `declare(strict_types=1);` を宣言すること
- 関数名は `filterAdultNames` とすること
- 引数は1つで、配列を受け取る(型宣言 `array` を付けること)
- 戻り値の型は `array` を宣言すること
- 関数内では `foreach` を使うこと(組み込み関数は使わない)
- 動作確認のため、関数を1回以上呼び出して結果を出力すること(`print_r` 推奨)
- **何も見ずに書くこと**(過去のコードや解説を見ない)

## 入力

なし(関数呼び出し時に直接配列を渡す)

入力例として使う配列:
```php
$users = [
    ['name' => 'Alice',   'age' => 25],
    ['name' => 'Bob',     'age' => 17],
    ['name' => 'Charlie', 'age' => 30],
    ['name' => 'Diana',   'age' => 19],
    ['name' => 'Eve',     'age' => 22],
];
```

## 出力例

上記の配列を渡した場合:
```
Array
(
    [0] => Alice
    [1] => Charlie
    [2] => Eve
)
```

(Bob は17歳、Diana は19歳なので除外)

## 取り組み方のヒント

- これまで Block 1 で書いた以下の要素を**組み合わせる**問題です
  - S8: 連想配列の配列の扱い(`$user['name']`、`$user['age']` で値を取り出す)
  - S19: 条件を満たす要素を抜き出すフィルター処理
  - S17: 型宣言と `strict_types`
- T1 と違い、扱うのが**連想配列の配列**(2階層)になっている点に注意
- ループの中で「ユーザー1人」を扱い、その中から `name` と `age` を取り出します
