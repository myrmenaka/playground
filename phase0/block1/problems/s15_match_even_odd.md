# S15: match 式で偶数・奇数の判定

S14 で書いた偶数・奇数判定を、PHP 8 の `match` 式を使って書き直してください。

## 進め方

このStepは**写経Step**です。

1. `solutions/s15_match_even_odd.php` を見ながら写経する
2. 動作確認後、ファイルを閉じて何も見ずに再現する
3. 余裕があれば、別の判定(正/負/ゼロなど)を `match` で書いてみる

## 仕様

- 数値を変数に代入する
- `match` 式で「2で割った余り」をキーに分岐する
- 偶数なら「偶数」、奇数なら「奇数」と出力する

## 出力例

`$num = 10` の場合:
```
偶数
```

`$num = 7` の場合:
```
奇数
```

## ファイル名

`my_answers/s15_match_even_odd.php`
