# PHP-B1-S10: 配列から値を削除する2パターン

## 概要

PHP の配列から値を削除する代表的な2つの方法を覚える。それぞれの違いを体感する。

## 学習目的

- 配列から値を削除する2つの方法を覚える
- `unset` と `array_pop` の挙動の違いを理解する
- 削除後のキー(インデックス)の状態を確認する

## 問題

5つの要素を持つインデックス配列を用意し、2つの異なる方法で値を削除して、最終的に3要素の配列にするプログラムを書いてください。
削除のステップごとに `print_r` で配列の中身を出力すること。

## 制約

- 最初は要素が5個のインデックス配列を用意すること(例: `[10, 20, 30, 40, 50]`)
- 以下の2つすべてのパターンを使って値を削除すること:
  - **パターン1**: `unset` 関数(指定したキーの要素を削除)
  - **パターン2**: `array_pop` 関数(配列の末尾から削除)
- 各削除の **直後に `print_r` で配列の中身を出力** すること
- 最終的に配列の要素数は3個になっていること

## 入力

なし(配列に直接値を代入する)

## 出力例

最初の配列が `[10, 20, 30, 40, 50]` で、`unset` でインデックス 1 を削除、`array_pop` で末尾を削除した場合:

```
Array
(
    [0] => 10
    [2] => 30
    [3] => 40
    [4] => 50
)
Array
(
    [0] => 10
    [2] => 30
    [3] => 40
)
```

(出力は実装によって少し異なります。順序や数値が一致していなくても、「指定方法で削除されている」「要素数が想定通り」ならOK)

## ヒント(必要な時だけ)

### パターン1: `unset` 関数

```php
$arr = [10, 20, 30];
unset($arr[1]);
// 結果: [0 => 10, 2 => 30]
//       ※ インデックス 1 が抜けて、キーが詰められない
```

- 指定したキーの要素を削除する
- **キーは詰められない**(インデックスが飛び石になる)

### パターン2: `array_pop` 関数

```php
$arr = [10, 20, 30];
$removed = array_pop($arr);
// $arr は [10, 20]、$removed は 30
```

- 末尾の要素を削除する
- 削除した値を **戻り値として返す**
- **元の配列を直接変更する**(参照渡し)

</details>

## 補足

- `unset` は **キーが詰められない** という特徴があり、ここが重要なポイント
- 業務では「削除後にキーを詰めたい」場合、`array_values()` という関数で再採番できる(これは別解として後で扱います)
