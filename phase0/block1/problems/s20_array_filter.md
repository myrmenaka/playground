# S20: array_filter で偶数を抽出

S19 で手書きした偶数フィルターを、PHP の組み込み関数 `array_filter` を使って書き直してください。
さらに、キーをリセットする処理も追加してください。

## 進め方

このStepは**写経Step**です。

1. `solutions/s20_array_filter.php` を見ながら写経する
2. 動作確認後、ファイルを閉じて何も見ずに再現する
3. 余裕があれば、`array_values` を使わない場合のキーの状態を確認する

## 仕様

- 関数名は `filterEven` とすること
- `array_filter` を使って偶数を抽出する
- 結果のキーを `0, 1, 2, ...` に振り直してから返すこと(`array_values` を使う)
- 動作確認のため、関数を2回以上呼び出して結果を出力すること

## 出力例

```
Array
(
    [0] => 2
    [1] => 4
    [2] => 6
)
Array
(
    [0] => 10
    [1] => 20
    [2] => 30
)
```

## 動作確認(余裕があれば)

写経後、以下のように `array_values` を外した場合のキーがどうなるか確認してみてください。

```php
print_r(array_filter([1, 2, 3, 4, 5, 6], fn($n) => $n % 2 === 0));
// キーが [1] => 2, [3] => 4, [5] => 6 と元のままになる
```
