# S19: 偶数だけを抽出する関数

整数の配列を受け取り、その中の偶数だけを集めた新しい配列を返す関数 `filterEven` を定義してください。

## 制約

- ファイル先頭で `declare(strict_types=1);` を宣言すること
- 関数名は `filterEven` とすること
- 引数は1つで、配列を受け取る(型宣言 `array` を付けること)
- 戻り値の型は `array` を宣言すること
- 関数内では `foreach` を使って処理すること(`array_filter` などの組み込み関数は次のStep S20 で扱うので使わない)
- 動作確認のため、関数を**2回以上**呼び出して結果を出力すること
- 結果の確認には `print_r` を使うこと

## 入力

なし(関数呼び出し時に直接配列を渡す)

## 出力例

`filterEven([1, 2, 3, 4, 5, 6])` を呼び出した場合:
```
Array
(
    [0] => 2
    [1] => 4
    [2] => 6
)
```

`filterEven([10, 15, 20, 25, 30])` を呼び出した場合:
```
Array
(
    [0] => 10
    [1] => 20
    [2] => 30
)
```

## ファイル名

`my_answers/s19_filter_even.php`

## ヒント

<details>
<summary>クリックで表示</summary>

- 結果を入れるための「空の配列」を関数の中で初期化する(例: `$result = [];`)
- `foreach` で各要素を取り出し、偶数判定(`% 2 === 0`)が true なら結果配列に追加する
- 配列に要素を追加するには `$result[] = $value;` と書く
- 最後に `$result` を `return` する
- `print_r($配列);` で配列を整形して出力できる(末尾に改行は自動で入らないので注意)
