# playground

個人学習・練習用リポジトリ。

学習トピックごとにディレクトリを分けて、コード・メモ・成果物を蓄積していく場所。

## 構成

| ディレクトリ | 内容 | 状態 |
|-------------|------|------|
| [`phase0/`](./phase0/) | PHP/Laravel 学習 Phase 0(書く力をつける) | 進行中 |
| [`docs/`](./docs/) | 学習プロジェクト全体に関わるドキュメント | - |
| [`references/`](./references/) | Phase横断の汎用リファレンス | - |

## 運用方針

- **学習トピックごとにディレクトリを切る**
- **規模が大きくなったり外部に見せたくなったら、そのトピックは専用リポジトリに切り出す**
- **小さな実験や試し書きはこのリポジトリに気軽に置く**

## このリポジトリについて

- **公開設定**: Public(学習記録として残す)
- **コミット粒度**: 小さく頻繁に。1Stepでも1ログでもコミットしてOK
- **完成度**: 学習過程なので未完成・実験的なコードも含む
